# Лабораторная работа 2

Разреженный вектор на C++17 с двумя хранилищами: AVL-дерево из ЛР1 и отсортированный
динамический массив с бинарным поиском. Хранятся только ненулевые значения и их индексы.
Реализованы Map, Where, Reduce, копирование, перемещение, графический интерфейс
на Dear ImGui, тесты и сравнение производительности.

## Запуск

Графическое приложение собирается для macOS, нужны Command Line Tools (`clang++`, `make`).
Dear ImGui 1.93.0 и GLFW 3.5.1 находятся в `gui/third_party/`, Metal входит в macOS SDK.
Устанавливать Homebrew и скачивать зависимости при сборке не требуется.
Источники и лицензии перечислены в [gui/third_party/README.md](gui/third_party/README.md).

```sh
make run
make run_tests
make check
```

`make` собирает `build/sparsevector_app` и пакет `build/SparseVector.app` со шрифтом.
`make run` открывает новое окно приложения. Пакет можно также открыть двойным нажатием
в Finder. Makefile содержит явные команды компиляции и зависимости от заголовков.
`make clean` удаляет объектные файлы, приложения и тестовые исполняемые файлы, сохраняя результаты.

`make tests` собирает тесты, `make run_tests` запускает их. `make check` отдельно собирает
и запускает тесты с AddressSanitizer и UndefinedBehaviorSanitizer.

## Работа с окном

Вверху выбирается хранилище и показываются длина N и количество ненулевых записей k.
У дерева и массива отдельные векторы; переключение сохраняет их данные в течение сеанса.

- **Вектор:** создание, генерация, таблица ненулевых пар, чтение, запись, удаление и очистка.
  Выбор строки заполняет поля индекса и значения. Индексы начинаются с нуля.
  Запись нуля удаляет пару; очистка сохраняет длину. При N ≤ 20 показывается полный вид.
- **Map / Where / Reduce:** исходный вектор и отдельный результат; кнопка
  «Сделать результат текущим» применяет результат Map или Where.
- **Сравнение:** эксперименты на текущем векторе или серия для разных k, таблица девяти
  операций, график и экспорт CSV. Подробнее ниже.

Таблица поддерживает прокрутку и рисует только видимые строки. Готовые данные для отображения
обновляются после изменений; полный обход контейнера на каждом кадре не выполняется.

В «Создать вектор» можно выбрать пустой вектор, полный список значений через пробел/перенос
строки или пары индекс/значение. Например, для N=5 список `0 7 0 -2 0` задаёт тот же вектор,
что пары `1 7` и `3 -2` на отдельных строках. Повторный индекс заменяется последней записью.
Для полного ввода доступно до 10000 значений, для пар — до 1000000 пар. N ограничено 10^9,
значения должны помещаться в int. Генератор выбирает ровно k различных позиций и ненулевые
значения заданного диапазона, без массива размером N. Порядок задаёт последовательность
вызовов Set. Одинаковые параметры и seed воспроизводят данные при той же реализации
стандартной библиотеки. Неудачный ввод или генерация не заменяют прежний вектор.

Map поддерживает смену знака, удвоение и квадрат. Where — положительные или чётные
значения. Они показывают независимый результат. Reduce суммирует ненулевые значения
с заданным начальным аккумулятором. Переполнение int выводится как ошибка.
Диалоги можно закрыть кнопкой «Отмена», приложение — кнопкой «Выход» или закрытием окна.
Длительные операции выполняются в одном рабочем потоке. Генерация проверяет отмену между
вставками, массовая загрузка и функциональные операции — перед принятием результата,
замеры — между завершёнными парами хранилищ. Закрытие приложения дожидается текущего этапа.
Отмена создания/генерации сохраняет прежний вектор; после отмены замеров доступны завершённые пары.

## Библиотечный интерфейс

```cpp
SparseVector<int> treeVector(1000);
SparseVector<int, ArrayStorage<int>> arrayVector(1000);
treeVector.Set(12, 7);
treeVector.Set(500, -3);
int missing = treeVector.Get(13); // 0
treeVector.Set(12, 0);          // удаление записи

auto mapped = treeVector.Map(NegateValue);
auto filtered = treeVector.Where(IsPositive);
int sum = treeVector.Reduce(SumValues, 0);
```

В примере нужны `lab2/SparseVector.hpp`, `lab2/ArrayStorage.hpp`, `lab2/VectorOperations.hpp`.
Последний заголовок содержит демонстрационные функции с проверкой переполнения.

- Map требует f(0)=0 и проверяет это отдельным вызовом функции. Нули результата удаляются.
- Where сохраняет исходные длину и индексы; отброшенные значения становятся нулевыми.
- Reduce обрабатывает только ненулевые записи по возрастанию индексов и вызывает
  `func(value, accumulator)`, как в ЛР1. При k=0 возвращается начальный аккумулятор.
- Обработчики не должны менять исходный контейнер или зависеть от количества вызовов.
- Конструктор из Sequence выполняет преобразование плотного вектора. FromEntries
  строит вектор из пар в произвольном порядке, с семантикой последней записи.
- Копии независимы; после перемещения исходный вектор имеет N=0 и k=0.
- GetEnumerator возвращает общий перечислитель ненулевых пар для обоих хранилищ.
  Используется исходный интерфейс IEnumerator с методами MoveNext, GetCurrent и GetCurrentKey.

Указатель Find в хранилище не владеет памятью; Get вектора
возвращает значение и не позволяет обойти правило удаления нулей.

## Замеры и графики

Во вкладке «Сравнение» доступны два режима:

- **На текущем векторе:** сравнение дерева и массива на одинаковых данных выбранного вектора.
- **Серия измерений:** максимальное k, фиксированное N либо N=10k, число повторов и seed.

Всегда проверяются случайный, возрастающий и убывающий порядки. Результаты содержат время
построения через Set, массовой загрузки, чтения ненулевых и нулевых позиций, обновления,
удаления, Map, Where и Reduce. В таблице выбирается k, для графика — операция и порядок.
Для одного k показываются столбцы двух хранилищ, для серии — две линии по фактическим
значениям k. Можно включить логарифмическую шкалу k; вертикальная ось показывает миллисекунды.
Таблица и график показывают медианы повторов, а кнопка «Сохранить CSV» записывает все повторы.
Путь по умолчанию — `gui/results/gui-benchmark.csv`, относительно корня проекта.

GUI и отдельная программа замеров используют общие `RunBenchmark`, `MeasureStorage` и
`WriteBenchmarkRecord` из `benchmarks/Benchmark.hpp`. Отрисовка, генерация данных, подготовка копий,
проверка результатов и экспорт CSV находятся вне измеряемых участков. GUI собирается с `-O2`.

Отдельную программу замеров и SVG-графики также можно запустить из терминала:

```sh
make run_benchmark
make plots
```

Бенчмарк собирается с `-O2`. По умолчанию измеряет k от 100 до 10 000, три порядка,
три повтора; N=10k. Каждый повтор записывается отдельно в gui/results/benchmark.csv.
Графики медиан сохраняются в gui/results/benchmark.svg; файл открывается в браузере.

Дополнительные параметры:

```sh
make benchmark
./build/benchmark 100000 3 17 gui/results/benchmark.csv 10000000
python3 gui/plot_benchmarks.py gui/results/benchmark.csv
```

Аргументы: максимальное k (1–10^6), число повторов (1–15), seed, путь CSV и необязательная
фиксированная длина N (до 10^9, не меньше максимального k). Без последнего аргумента
N=10k для каждого размера. Последовательность размеров: 100, 300, 1000, 3000 и далее;
заданный максимум включается, даже если его нет в списке.

Для сохранённого из окна CSV графики можно дополнительно построить командой
`python3 gui/plot_benchmarks.py gui/results/gui-benchmark.csv`. Для этого нужен Python 3.6 или новее,
сторонние Python-пакеты не используются.

Времена относятся ко всему пакету, а не к одному обращению: построение, чтение, обновление
и удаление — k операций. Чтение нулевых позиций — min(k, N−k) запросов; если вектор полностью
заполнен, таких запросов нет. Массовое построение включает сортировку, если она нужна.
Map identity копирует значения, Where оставляет положительные, Reduce вычисляет XOR —
это позволяет сравнивать произвольные int без переполнения суммы. Генерация, контроль
результатов, подготовка копий и ввод-вывод не входят в измеряемые участки.

Исходные пары и значения одинаковы для хранилищ и трёх порядков при фиксированных N, k
и seed. В повторах seed увеличивается на номер повтора, начиная с нуля. Порядок запуска
хранилищ чередуется. Код проверяет значения и размеры результатов; CSV содержит контрольные
суммы. Скрипт строит девять панелей с медианами; обе оси логарифмические.

Фактически выполненные измерения и выводы находятся в [gui/results/README.md](gui/results/README.md).
Большие случайные и обратные вставки в массив имеют квадратичную стоимость: поддержка
параметра k=10^6 не означает, что такой запуск уже выполнен или будет быстрым.

## Сложность

Для k ненулевых записей и постоянной стоимости сравнения и копирования int:

| Операция | AVL | Массив |
|---|---:|---:|
| Get, обновление существующей записи | O(log(k+1)) | O(log(k+1)) |
| Новая запись, удаление | O(log(k+1)) | O(k), поиск + сдвиг |
| Построение через Set | O(k log(k+1)) | O(k²) в худшем случае |
| Построение через Set с возрастающими индексами | O(k log(k+1)) | O(k log(k+1)) |
| Массовая загрузка уже упорядоченных уникальных пар | O(k log(k+1)) | O(k) |
| Map, Where | O(k log(k+1)) | O(k) |
| Reduce, полный обход | O(k) | O(k) |
| Дополнительная память перечислителя | O(log(k+1)) | O(1) |

Память контейнера — O(k), она не зависит от N. Массив имеет запас ёмкости и увеличивает
её геометрически. Для типов с потенциально бросающим присваиванием изменения массива
выполняются через временную копию, поэтому даже обновление может требовать O(k).
Эта цена обеспечивает сохранение исходных данных при исключениях.
