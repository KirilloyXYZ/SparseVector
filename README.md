# Лабораторная работа 2

Разреженный вектор на C++17 с двумя хранилищами: AVL-дерево из ЛР1 и отсортированный
динамический массив с бинарным поиском. Хранятся только ненулевые значения и их индексы.
Реализованы Map, Where, Reduce, копирование, перемещение, консольное меню, тесты и сравнение
производительности.

## Запуск

Нужны компилятор C++17 и make. Сторонние библиотеки C++ не используются.
Для графиков нужен Python 3.6 или новее; устанавливать пакеты не требуется.

```sh
make run
make run_tests
make check
```

Makefile использует явные команды g++ и зависимости от заголовков. Приложение и тесты
сначала компилируются в main.o и tests.o, затем связываются в исполняемые файлы.
На macOS команда g++ может запускать Apple Clang. `make clean` удаляет объектные и
исполняемые файлы и сохраняет результаты.

`make tests` собирает тесты, `make run_tests` запускает их. `make check` отдельно собирает
и запускает тесты с AddressSanitizer и UndefinedBehaviorSanitizer.

В главном меню выбирается хранилище. В каждом подменю доступны ввод, генерация, чтение,
запись, очистка, просмотр, Map/Where/Reduce и сравнение хранилищ. Числа вводятся по одному
на строке. Индексы начинаются с нуля. Запись нуля удаляет пару; Clear сохраняет длину.
Для небольших векторов дополнительно показывается полный вид, для больших — первые
100 ненулевых записей. После возврата к выбору хранилища данные обоих векторов сохраняются.

Ручной ввод поддерживает все значения либо пары индекс/значение. Повторный индекс
заменяется последней записью. Генератор выбирает ровно k различных позиций и ненулевые
значения заданного диапазона, без массива размером N. Порядок задаёт последовательность
вызовов Set. Одинаковые параметры и seed воспроизводят данные при той же реализации
стандартной библиотеки. Неудачный ввод или генерация не заменяют прежний вектор.

Map поддерживает смену знака, удвоение и квадрат. Where — положительные или чётные
значения. Они показывают независимый результат. Reduce суммирует ненулевые значения
с заданным начальным аккумулятором. Переполнение int выводится как ошибка.
Конец ввода завершает программу, включая незавершённый ввод вектора.

## Библиотечный интерфейс

```cpp
SparseVector<int> treeVector(1000);
SparseVector<int, ArrayStorage<int>> arrayVector(1000);
treeVector.Set(12, 7);
treeVector.Set(500, -3);
int missing = treeVector.Get(13); // 0
treeVector.Set(12, 0);          // удаление записи

auto mapped = treeVector.Map(NegateValue);
auto filtered = treeVector.Where(IsPositive);
int sum = treeVector.Reduce(SumValues, 0);
```

В примере нужны `SparseVector.hpp`, `ArrayStorage.hpp`, `VectorOperations.hpp`.
Последний заголовок содержит демонстрационные функции с проверкой переполнения.

- Map требует f(0)=0 и проверяет это отдельным вызовом функции. Нули результата удаляются.
- Where сохраняет исходные длину и индексы; отброшенные значения становятся нулевыми.
- Reduce обрабатывает только ненулевые записи по возрастанию индексов и вызывает
  `func(value, accumulator)`, как в ЛР1. При k=0 возвращается начальный аккумулятор.
- Обработчики не должны менять исходный контейнер или зависеть от количества вызовов.
- Конструктор из Sequence выполняет преобразование плотного вектора. FromEntries
  строит вектор из пар в произвольном порядке, с семантикой последней записи.
- Копии независимы; после перемещения исходный вектор имеет N=0 и k=0.
- GetEnumerator возвращает общий перечислитель ненулевых пар для обоих хранилищ.
  Используется исходный интерфейс IEnumerator с методами MoveNext, GetCurrent и GetCurrentKey.

Указатель Find в хранилище не владеет памятью; Get вектора
возвращает значение и не позволяет обойти правило удаления нулей.

## Замеры и графики

```sh
make run_benchmark
make plots
```

Бенчмарк собирается с `-O2`. По умолчанию измеряет k от 100 до 10 000, три порядка,
три повтора; N=10k. Каждый повтор записывается отдельно в results/benchmark.csv.
Графики медиан сохраняются в results/benchmark.svg; файл открывается в браузере.

Дополнительные параметры:

```sh
make benchmark
./benchmark 100000 3 17 results/benchmark.csv 10000000
python3 plot_benchmarks.py results/benchmark.csv
```

Аргументы: максимальное k (1–10^6), число повторов (1–15), seed, путь CSV и необязательная
фиксированная длина N (до 10^9, не меньше максимального k). Без последнего аргумента
N=10k для каждого размера. Последовательность размеров: 100, 300, 1000, 3000 и далее;
заданный максимум включается, даже если его нет в списке.

Пункт сравнения в меню запускает обе реализации на содержимом текущего вектора для
трёх порядков вставки и сохраняет CSV. Он не меняет текущий вектор.

Времена относятся ко всему пакету, а не к одному обращению: построение, чтение, обновление
и удаление — k операций. Чтение нулевых позиций — min(k, N−k) запросов; если вектор полностью
заполнен, таких запросов нет. Массовое построение включает сортировку, если она нужна.
Map identity копирует значения, Where оставляет положительные, Reduce вычисляет XOR —
это позволяет сравнивать произвольные int без переполнения суммы. Генерация, контроль
результатов, подготовка копий и ввод-вывод не входят в измеряемые участки.

Исходные пары и значения одинаковы для хранилищ и трёх порядков при фиксированных N, k
и seed. В повторах seed увеличивается на номер повтора, начиная с нуля. Порядок запуска
хранилищ чередуется. Код проверяет значения и размеры результатов; CSV содержит контрольные
суммы. Скрипт строит девять панелей с медианами; обе оси логарифмические.

Фактически выполненные измерения и выводы находятся в [results/README.md](results/README.md).
Большие случайные и обратные вставки в массив имеют квадратичную стоимость: поддержка
параметра k=10^6 не означает, что такой запуск уже выполнен или будет быстрым.

## Сложность

Для k ненулевых записей и постоянной стоимости сравнения и копирования int:

| Операция | AVL | Массив |
|---|---:|---:|
| Get, обновление существующей записи | O(log(k+1)) | O(log(k+1)) |
| Новая запись, удаление | O(log(k+1)) | O(k), поиск + сдвиг |
| Построение через Set | O(k log(k+1)) | O(k²) в худшем случае |
| Построение через Set с возрастающими индексами | O(k log(k+1)) | O(k log(k+1)) |
| Массовая загрузка уже упорядоченных уникальных пар | O(k log(k+1)) | O(k) |
| Map, Where | O(k log(k+1)) | O(k) |
| Reduce, полный обход | O(k) | O(k) |
| Дополнительная память перечислителя | O(log(k+1)) | O(1) |

Память контейнера — O(k), она не зависит от N. Массив имеет запас ёмкости и увеличивает
её геометрически. Для типов с потенциально бросающим присваиванием изменения массива
выполняются через временную копию, поэтому даже обновление может требовать O(k).
Эта цена обеспечивает сохранение исходных данных при исключениях.
